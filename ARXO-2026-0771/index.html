ARXO-2026-0771 · Reported

Department of the Treasury: 20 references to U.S. Code sections repealed, omitted or not in the Code (31 CFR)

In the CFR chapters assigned to the Department of the Treasury in 31 CFR, 20 references in 20 sections cite a U.S. Code section that release point 119-134 of the U.S. Code does not carry in force: 17 cite a number the Code does not have; 3 cite a repealed section. The release names no successor for these sections.

Consequence

A reader who follows these references does not reach the text the rule relies on. No effect on a decision or an amount has been established.

Proposed correction

The agency decides whether to remove or replace each reference. The U.S. Code names no successor for these sections.
