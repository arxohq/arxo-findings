ARXO-2026-0004 · Editorial note added

26 U.S.C. §42(i)(3)(C)(ii) defines a related person by reference to “subsection (d)(2)(D)(iii)”, which no longer exists

Section 42(i)(3)(C)(ii) excludes units owned by a person “related (as defined in subsection (d)(2)(D)(iii))” to the occupant. P.L. 110-289 §3003(e) and (g)(2) redesignated that definition as subsection (d)(2)(D)(ii), which now reads “(ii) Related person”; subparagraph (D) has no clause (iii).

Proposed correction

Refer to subsection (d)(2)(D)(ii).
