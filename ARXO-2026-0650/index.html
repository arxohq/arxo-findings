ARXO-2026-0650 · Reported

Fetch: the response to a top-level navigation cannot set an ordinary cookie

Set-Cookie processing allows Strict, Lax and unset cookies only when the mode is the highest one. A top-level GET navigation never gets that mode, so by the text its response cannot store these cookies. RFC 6265bis notes that top-level navigations can create a cookie with any SameSite value.

Consequence

A response to a top-level GET navigation sets a=1 or a SameSite=Lax cookie: by the text it is not stored; Chromium 156, Firefox 157 and WebKit 27.2 store it.

Proposed correction

Also allow these cookies for top-level navigations.
