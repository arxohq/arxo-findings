ARXO-2026-0106 · Reported

Disclosure item for a Fund Manager acting itself as custodian of Real Property points to CIS 7.3(e), which the same amending instrument deleted

CIS 5.3(l)(viii) requires three disclosures "If the Fund Manager itself acts as the custodian of Real Property, in accordance with CIS 7.3.(e)". CIS 7.3(e) reads "[intentionally omitted]": Amendments No. 3 (in force 1 June 2023) inserted 5.3(l)(viii) with this reference and, on the same page, deleted the whole of 7.3(e), which was the custody exemption for a Self-managed Fund. The reference therefore has no target. A Fund may still have no Eligible Custodian under 8.2(b), or under a waiver (8.2(e) or 1.3), but CIS does not describe any of these cases as the Fund Manager itself acting as custodian, so it is unclear when the disclosure applies. The draft in Consultation Paper AFSA-PSRD-CSP-2026-0001 deletes the words "Subject to Rule (e), and" in 7.3(d) but moves the disclosure item, with the same reference to 7.3(e), into the new CIS 5.6.2(h).

Proposed correction

Please state which case the item (5.3(l)(viii), in the draft 5.6.2(h)) is meant to cover and correct the reference: (a) to CIS 8.2(b) or 8.2(e), if those cases are meant; or (b) to a new rule that allows a Fund Manager to act as custodian of Real Property, with conditions. If no such case is intended, the item can be removed.
