ARXO-2026-0671 · Reported

Department of Agriculture: 130 references to U.S. Code sections repealed, omitted or not in the Code (7 CFR, subtitle A, parts 1 to 23)

In the CFR chapters assigned to the Department of Agriculture in 7 CFR, subtitle A, parts 1 to 23, 130 references in 38 sections cite a U.S. Code section that release point 119-134 of the U.S. Code does not carry in force: 96 cite a repealed section; 26 cite a number the Code does not have; 8 cite a section omitted from the Code. The release names no successor for these sections.

Consequence

A reader who follows these references does not reach the text the rule relies on. No effect on a decision or an amount has been established.

Proposed correction

The agency decides whether to remove or replace each reference. The U.S. Code names no successor for these sections.
