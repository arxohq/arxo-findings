ARXO-2026-0746 · Reported

Department of Agriculture: 25 references to U.S. Code sections repealed, omitted or not in the Code (36 CFR)

In the CFR chapters assigned to the Department of Agriculture in 36 CFR, 25 references in 20 sections cite a U.S. Code section that release point 119-134 of the U.S. Code does not carry in force: 14 cite a repealed section; 9 cite a number the Code does not have; 2 cite a section omitted from the Code. The release names no successor for these sections.

Consequence

A reader who follows these references does not reach the text the rule relies on. No effect on a decision or an amount has been established.

Proposed correction

The agency decides whether to remove or replace each reference. The U.S. Code names no successor for these sections.
