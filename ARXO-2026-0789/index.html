ARXO-2026-0789 · Reported

Government Accountability Office: 2 references to U.S. Code sections repealed, omitted or not in the Code

In the CFR chapters assigned to the Government Accountability Office, 2 references in 1 section cite a U.S. Code section that release point 119-134 of the U.S. Code does not carry in force: 2 cite a number the Code does not have. The release names no successor for these sections.

Consequence

A reader who follows these references does not reach the text the rule relies on. No effect on a decision or an amount has been established.

Proposed correction

The agency decides whether to remove or replace each reference. The U.S. Code names no successor for these sections.
