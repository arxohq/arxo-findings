ARXO-2026-0728 · Reported

Department of Agriculture: 20 references to U.S. Code sections repealed, omitted or not in the Code (7 CFR, chapter II, parts 220 to 283)

In the CFR chapters assigned to the Department of Agriculture in 7 CFR, chapter II, parts 220 to 283, 20 references in 9 sections cite a U.S. Code section that release point 119-134 of the U.S. Code does not carry in force: 8 cite a number the Code does not have; 7 cite a section omitted from the Code; 5 cite a repealed section. The release names no successor for these sections.

Consequence

A reader who follows these references does not reach the text the rule relies on. No effect on a decision or an amount has been established.

Proposed correction

The agency decides whether to remove or replace each reference. The U.S. Code names no successor for these sections.
