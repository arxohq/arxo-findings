Department of the Interior: 59 references to U.S. Code sections repealed, omitted or not in the Code (25 CFR)

In the CFR chapters assigned to the Department of the Interior in 25 CFR, 59 references in 47 sections cite a U.S. Code section that release point 119-134 of the U.S. Code does not carry in force: 29 cite a section omitted from the Code; 17 cite a number the Code does not have; 13 cite a repealed section. The release names no successor for these sections.

Consequence

A reader who follows these references does not reach the text the rule relies on. No effect on a decision or an amount has been established.

Proposed correction

The agency decides whether to remove or replace each reference. The U.S. Code names no successor for these sections.
