ARXO-2026-0680 · Reported

Department of Defense: 5 references with a wrong U.S. Code section or act name

In the CFR chapters assigned to the Department of Defense, 5 references in 5 sections cite the U.S. Code or an act with an error: 3 name a U.S. Code section that is not part of the act named next to it; 2 name an act differently from the U.S. Code. Each reference was compared with release point 119-134 of the U.S. Code published by the Office of the Law Revision Counsel.

Consequence

A reader who follows these references reaches a different section or looks for an act under a name the U.S. Code does not use. No effect on a decision or an amount has been established.

Proposed correction

The agency decides how to correct each reference. Where the U.S. Code shows the section or the name intended, the evidence below gives it.
