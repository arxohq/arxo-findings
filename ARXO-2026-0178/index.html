ARXO-2026-0178 · Reported

Companies Rules 5.3 (transfer out of the AIFC): since V4 the subrules are numbered 5.3.3-5.3.6, and three cross-references, including the 60-day notice, point to numbers that no longer exist

In the Companies Rules V1-V3, rule 5.3 has 5.3.1 (application, with (c) "a declaration ... under subrule 5.3.3"), 5.3.2, 5.3.3 ("For rule 5.3.1(c), the declaration ... must state") and 5.3.4 (60-day notice before "an application mentioned in subrule 5.3.1"). From V4 (in force 1 January 2020) the same subrules are numbered 5.3.3-5.3.6 and there is no 5.3.1 or 5.3.2, but the text is unchanged. So 5.3.3(c) now points to itself, 5.3.5 points to "5.3.1(c)" and 5.3.6 ties the 60-day notice to "an application mentioned in subrule 5.3.1". The Companies Rules on the AFSA website (read on 24 October 2026) have the same numbering. No published amending act changes rule 5.3. Rule 5.3 deals with one application only, so the meaning can be recovered.

Proposed correction

Please restore the numbering 5.3.1-5.3.4 of rule 5.3, as in V1-V3, so that the references in the rule resolve again.
