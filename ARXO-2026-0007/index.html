ARXO-2026-0007 · Editorial note added

26 U.S.C. §877(a)(2) substitutes “2003” for “1992” in §1(f)(3)(B), which no longer contains “1992”

Section 877(a)(2) adjusts the $124,000 tax-liability threshold for expatriates by the cost-of-living adjustment under section 1(f)(3) “by substituting ‘2003’ for ‘1992’ in subparagraph (B) thereof”. Section 1(f)(3)(B) no longer contains “1992”, so the substitution finds nothing to replace. The threshold is still used: §877A defines a covered expatriate through §877(a)(2).

Proposed correction

For the legislature to state the base year and the provision to which it applies.
