ARXO-2026-0019 · Reported

LF 2026 art. 81, V: « code général des collectivité territoriales » (missing plural in the name of the code)

Article 81, V, of Law No. 2026-103 (2026 Finance Act) introduces amendments to « La deuxième partie du code général des collectivité territoriales ». The code is the « code général des collectivités territoriales », as the same article writes it elsewhere. The final text adopted by the National Assembly (T.A. No. 227) carries the same spelling, so the discrepancy is in the adopted text; the code referred to remains identifiable.

Proposed correction

Read « code général des collectivités territoriales ».
