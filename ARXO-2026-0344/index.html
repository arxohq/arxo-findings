ARXO-2026-0344 · Reported

OAuth 2.1 draft: §6.1.1 attributes the OAuth Extensions Error Registry to RFC 6750

§6.1.1 says RFC 6750 establishes the OAuth Extensions Error Registry and points to Section 11.4 of RFC 6749 in the same sentence. The registry was established by RFC 6749 (Sections 7.2 and 11.4); RFC 6750 only registers values in it, and §11 of the draft says it does not require any IANA actions. Draft-17 corrected the second paragraph of §6.1.1; this sentence remains.

Consequence

An author of an OAuth extension is told that RFC 6750 established the registry where error values are registered.

Proposed correction

Say that RFC 6749 (Section 11.4) establishes the OAuth Extensions Error Registry.
